# LINE Native GUI 1.4.0

## 基礎機能の強化

### メディアキャッシュ

`TalkMessage.getData()` で一度取得できたメディアをローカルの `media-cache/` に保存する。以後は同じチャット/MID・メッセージID・preview/fullの組み合わせからローカルコピーを再利用できる。

HTTP 410 は `MEDIA_GONE` として扱い、取得不能状態をキャッシュする。これにより、履歴描画のたびに同一メディアへ再要求するループを避ける。

### スタンプ

`contentMetadata` の `STKVER` / `STKPKGID` / `STKID` を正規化して、最近見たスタンプをGUIのピッカーへ登録する。ピッカーからの再送と手動ID入力の両方を用意する。

送信はTalk `contentType=7` の通常経路を使用し、`e2ee:false` を明示する。現在のカスタムE2EEテキスト経路を流用したことにはしない。

### UI

コンポーザーにファイル添付 `＋` とスタンプ `🙂` を並べる。スタンプピッカーは最近のスタンプをグリッド表示し、選択したパッケージID・スタンプID・バージョンをそのまま再送できる。

## 検証

NodeのテストスイートとJavaScript構文チェックを行う。実際のLINEアカウントでのスタンプ送信・メディア取得のライブ検証は、この環境では行っていない。
